# Toy Haven Front-End Website

## Files
- index.html — Home
- products.html — Product listing/search/filter
- cart.html — Shopping cart
- checkout.html — Checkout and validation
- success.html — Successful order
- wishlist.html — My Collection
- feedback.html — Feedback and FAQ
- css/style.css — Responsive styling and animations
- js/products.js — Product data
- js/app.js — Reusable JavaScript functionality
- manifest.json — PWA manifest
- favicon.svg — Favicon

## Run locally
Open `index.html` in a browser. For best results, use VS Code Live Server.

## GitHub Pages
Upload the entire folder to a GitHub repository, then enable GitHub Pages from Settings > Pages using the main branch and root folder.

## Notes
Product/cart/wishlist/feedback/newsletter/order data use browser localStorage.
